# Local Turístico

Landing Page de turismo desenvolvida com HTML e CSS durante as aulas iniciais de desenvolvimento web, com foco na prática de estruturação de páginas e estilização básica.

## Objetivo

O projeto tem como objetivo a prática de criação de uma landing page, aplicando os conceitos iniciais de HTML e CSS aprendidos em aula.

---

## Tecnologias Utilizadas

* **Front-end:** HTML5 e CSS3

---

## Como Acessar e Rodar

O projeto pode ser acessado diretamente pelo navegador:

🔗 [Acessar o projeto online](https://mayconsantos04.github.io/Local-Turistico/)

---

### Execução Local

Caso queira executar o projeto localmente, siga os passos abaixo:

1. Clone o repositório:

```bash
git clone https://github.com/MayconSantos04/Local-Turistico.git
```

2. Acesse a pasta do projeto:

```bash
cd Local-Turistico
```

3. Abra o projeto no VS Code:

```bash
code .
```

4. Abra o arquivo `index.html` diretamente no navegador.

---

## Sobre o Projeto

Neste desafio, foi desenvolvido uma Landing Page de turismo utilizando apenas HTML e CSS. A página apresenta informações sobre locais turísticos, com imagens e textos descritivos, buscando praticar a estruturação semântica do HTML e a estilização com CSS para criar um layout simples e organizado.
